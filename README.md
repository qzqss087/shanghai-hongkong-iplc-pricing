## 沪港 IPLC 是一条什么线

这条线的结构是：国内侧从上海接入（共享版走上海电信，独享版走 UCloud 上海 BGP），跨境段是点对点 IPLC 专线，出口在香港 BGP。官方给所有沪港产品的端内参考延迟统一是 21ms。

这里要解释一下 21ms 的含义。它是产品"端内"的参考值，也就是从上海入口到香港出口这段专线的延迟，不是你家里电脑到目标网站的完整耗时。你的真实体验还要加上"本地宽带到上海入口"和"香港出口到目标平台"两段，官方知识库也专门强调了这一点，避免用户拿 21ms 当成全程延迟预期。

交付形态上，你买的是一台 VPS，每台分配 1 个独立入口 IP 和 1 个独立出口 IP。你连入口 IP 操作机器，程序从香港出口 IP 向外访问。这个"双端独立 IP"结构是专线 VPS 区别于共享网关类产品的主要特征，对需要固定出口做后台、接口类业务的人来说是刚需配置。

香港出口侧的线路资源，官方列了 PCCWG、RETN、NTT、Cogent、Lumen、Telstra、HE、Voxility 等多家运营商互联，接入 Equinix IX / HKIX 等交换中心，还有到 Google、Cloudflare、Valve、SGGS 的私有 PNI。不过官方自己也补了一句实话：这不代表所有目标网站都走私有直连，出口到目标服务仍有后续路径。

相比广港 IEPL 的 1~2ms 端内延迟，沪港 21ms 看起来不占优，但两者的意义不同：广港适合华南用户就近接入，沪港则是上海及华东方向到香港的直连选择，对上海本地宽带来说入口物理距离更近。

## 共享、独享、IXP：差价到底差在哪

同样是"上海到香港"，三种计费模式的成本逻辑完全不同，价格差得远也正常。

**共享流量版**卖的是峰值带宽加月流量额度。200Mbps 峰值听起来很猛，但它是共享带宽，官方明确不保证持续跑满；流量按上行加下行双向统计，用完就暂停，可以在后台花原价 9 折自助重置，或者补差价升级套餐。适合的场景是流量有波峰的业务：定时上传素材、后台批量操作、备份同步这类"短时间冲一下"的活。

**独享带宽版**反过来，速率是你专用的、保证的，流量随便跑。5Mbps 独享折合持续传输大约 600KB/s 出头，数字不大，但胜在 24 小时稳定，适合 ERP、CRM、持续数据同步这种要"细水长流"的业务。为什么比共享贵一倍以上？因为独享带宽占用的线路资源是锁定的，不受其他人影响。

**IXP 版本**价格最低，原因是接入方式变了：入口走云厂优化网络通道，你不直接从家里宽带连，而是先连到阿里云、腾讯云这类云厂机器上，再由云厂网络进入专线。省下的接入成本让利给了价格，代价是你必须先买一台云厂 VPS 当前置，这笔前置费用要算进总预算。另外 IXP 的入口 IP 只在云厂内网可达，普通宽带连不上，第三方测评（虎窝博客的沪港 IXP 测评）也确认了这个特性。

官方知识库给的选型矩阵可以概括成三句话：流量有波峰选共享，持续速率需求选独享，已经有云厂机器的选 IXP。按用量选，别按"主号用独享、小号用共享"这类说法选——官方专门澄清过，共享和独享的 IP 数量一样，账号能不能过平台审核和这个无关。

## 常见问题

**21ms 是我打开香港网站的总延迟吗？**
不是。它是上海入口到香港出口的端内参考值，全程还要加上本地到入口、出口到目标两段路径。

**流量是单向还是双向？超了会怎样？**
计量型套餐按上行、下行双向统计，达到额度暂停服务，可自助 9 折重置流量或补差价升级。

**能拿来建站或做机场吗？**
都不能。出口不支持入站，不能公开建站；机场等用途在禁止清单里，违者清退不退款。

**怎么付款、支持退款吗？**
支付走支付宝（官方隐私政策和第三方测评口径一致）；仅质量问题可退款，需提供测试数据证据，开通后不能换地域。

**沪港 IPLC 和沪港 IX（IXP）怎么选？**
能从绑定省份直连入口选 IPLC；已经有支持的云厂网络选 IXP。两者端内延迟同为 21ms，主要差别在接入方式和价格。
